
本阶段只建地面、水文外形、海面参考和显示底座。建筑、道路、护岸工程资产、桥梁和交互查看器不是已完成项。
模型集合、材质与相机可编辑。打开文件的3D视图已设定城市范围与足够的远裁切距离；相机初始为城市顶视。

## 坐标与控制位置

工作坐标保持 **EPSG:32611 / WGS84 UTM11N**。洛杉矶位于该分区，米制、区域畸变小，兼容现有原点与DEM。
原点仍为 Downtown 参考街区投影质心：UTM `(384992.75594820484, 3767182.3649733574)` 米；经纬度 `(-118.24590326933966, 34.03901922388071)`。
X为投影网格东，Y为投影网格北，Z向上。所有地面Z使用NAVD88米，垂直偏移0、夸张1。
这个Z偏移是坐标约定，不是把第一阶段合成origin_height_m=0当成实测地面。

完整WKT、PROJJSON、安装环境实际选用的水平转换pipeline、精度声明、缺失操作数量、4×4矩阵在 `data/processed/stage03/coordinate_system.json`。
经纬度到投影是非线性转换，使用PROJ管线；4×4矩阵负责UTM、本地城市和分块坐标的平移，不能以矩阵冒充经纬度投影。
原始EPSG4269、6424、26911、5070等基准与文件原字节保留；没有把LARIAC ELEV或未知基准高度混入地面。
NAVD88正高不等于WGS84椭球高，本阶段没有大地水准面或潮位基准转换。

每块局部XY控制在0–1000米，保留NAVD88 Z；对象仅平移到城市原点附近。所有模型世界坐标绝对值小于约38.74公里。
每块保存局部到UTM/Blender及逆矩阵、地理多边形、包围盒、邻接、原始分辨率、采样密度、LOD、哈希与版本。
投影北与真北的子午线收敛角、真北在Blender中的实际方向向量、局部投影比例逐控制点记录，不套一个全市固定旋转角。

12个控制位置包括市中心、官方地标、LAX、Van Nuys机场和市界极值。它们是可追溯的**计算参考位置**，不是测量控制网。
执行了经纬度往返、UTM中央经线解析检查、构造的1公里/4公里已知网格基线、独立椭球距离/方位关系、英尺/美国测量英尺/英寸单位转换和Blender重开后对应位置测量。
计算往返最大约9.31×10⁻¹⁰米；Blender float32保存及对象矩阵对应最大约0.00189米。
这些不能称为原始数据测绘精度；原始水平/垂直数字精度仍未知，坐标操作自身的名义精度单独列出。

```bash
.venv/bin/python scripts/stage03_coordinates.py --to local -118.24590326933966 34.03901922388071 --height-navd88-m 100
.venv/bin/python scripts/stage03_coordinates.py --to geographic 0 0 --height-navd88-m 100
```

最终控制报告：`work/reports/stage03/controls_city_medium_final.json`；计算前置报告和原始位置也保留。

## 地形、分辨率与修整

使用阶段二USGS bare-earth DEM，属于裸地DTM来源，未以建筑/树冠DSM替代。
全市原始标准网格约10米，Downtown原始标准网格1米。中档生成网格为全市50米、Downtown10米、近景5米，并沿真实面状河道局部加密到10米。
网格采样比源数据疏，不声称获得更高原始精度。工业/公园颜色、平滑法线也不改变地形顶点高程。

实际检查：全市范围原DEM有81个NoData像素，Downtown范围完整；配置高度范围−500至5000米内没有异常值。
邻像素高差分位数和极值在dem_audit.json；保留山地、谷地、平原与海岸关系，不作高度夸张。
原始和阶段二标准DEM都未修改。仅有以下明确处理：

- Downtown外缘100米过渡带按距边界距离混合1米/10米DEM，公共边界严格使用共同高度函数。两源差异的中位数约−0.015米，最大绝对差约10.47米，不能把差异平滑称为提高精度。
- 对完全缺测的网格采样，仅允许30米内最近有效DEM值修补；本次地形生成有7个记录位置，见height_repairs.json，明确标记inferred。超出限度会省略无效面，不能产生NaN顶点。本次无省略的缺测面。
- 法线由相同世界坐标处的DEM梯度生成，仅影响光照。实际检查所有相邻LOD法线一致，防止产生光照块缝。
- 水文叠加中的微小零面积/重复裁切面在float32量化后隔离计数，未修改原始水体边界；见water_medium.json。

## 分块与LOD

500米、1000米双块试验均实际运行并核对公共边界。选择1000米，减少全市对象/文件数量，保持局部数值范围合理。
生成1554块：`data/processed/stage03/medium/tile_index.json`与`.geojson`。
稳定ID为 `la_t_x±NNN_y±NNN`，坐标基于固定原点，边界归属采用半开区间；整城外边界仍按实际行政几何裁切，保留孔洞/离散部分。

LOD0为分级自适应网格，LOD1/2内部为100/250米。**所有LOD的分块外边都保留同一套最细边界点**，粗细连接使用约束边和过渡扇形，不用覆盖裙边掩盖地形裂缝。
全部2906邻接对、每对9种混合LOD实际检查，26154组合的坐标/高程差最大0米；无未配对内边或非流形地形边。
有1554份可独立读取的NPZ，每份v0/f0/m0/n0至v2/f2/m2/n2分别为局部顶点、三角形、材质索引、平滑法线。

中档LOD0全量1,587,519三角形；全市检查场景静态选752块使用LOD1，其他块保留LOD0，优先保留Downtown与精细区。
加上水体和底座后实际可见1,499,712三角形，小于150万预算。其他LOD集合在.blend中隐藏保留。
这是本次检查点的**静态选择**，没有声称已实现随相机距离运行时切换；该功能仍属于后续查看器阶段。

## 水体、河段与海岸

以Census2025实际水面/海岸几何制作206个原始水文对象、576个分块子件。原始ID为父对象，子件归属实际网格，跨块使用相同父级水面规则。
水体469个邻接对实际检查，公共边最大误差约2.03×10⁻⁶米。最终Blender全部水体顶点有限、无退化面。

水面分为三类，必须保留其含义：

- DEM岸边采样高差小的湖泊/水库，使用DEM估计平面。没有水位站或当期测量，不称实测水位。
- 河道或岸边高差大的对象，使用贴合真实地面网格的水文参考掩膜，加0.03米显示偏移避免重叠闪烁。这是地理水文范围显示，不是水动力模型或当前湿水宽度。
- 海洋/海湾集合独立组织，使用NAVD88坐标轴上0米的项目显示参考平面，未把它叫作MSL/MHW/MLLW，也未混入未经转换的潮位基准。没有海底测深建模。

河道不以中心线随意buffer成“真实水流”。线水文省略了Downtown附近的面状洛杉矶河河段，已使用原始面水文补充109个分块河段；另保留36个原生线河段。
从已取得的原始1米裸地DEM实际提取7条邻近Downtown的河槽调查剖面，位置按真实水面横断，不移动河流或扩大原工作窗来构图。
剖面窗口宽度不是流宽，横断是地形调查，不是工程测量。逐段护岸材料、工程断面、当期水流和桥面高程仍缺，明确unknown，不把全部河岸归成自然或混凝土，不伪造桥梁。
源海岸线在独立隐藏参考集合保存，只有XY地理位置可核；其显示Z不证明潮位岸线基准。

## 地表类别与资料边界

基础颜色由NLCD2021分类和已核对的官方设施/规划多边形得到，原始30米分类不被描述为近景材质精度。
建成区、公园、森林、开放植被色带、裸地、湿地、水面及海面分别保留。dry_slope是52/71/81/82的显示分组，包含灌丛、草地、牧草/耕地，不能据颜色断言每处都是干燥斜坡；公园域颜色也不表示每个像素都有植被。原始类别保留，显示分组依据和推断见surface_classification.json。
补取并核对City Planning官方1005个工业/机场规划要素，其中963工业、42机场，以及官方Port of Los Angeles规划区1个。
使用明确NAME_ALF精确选港区；名称包含port的Porter Ranch、机场不会误入港口类别。
工业/仓储及港区颜色表示**规划指定范围辅助分类**，不是当前逐地块实际用途；资料不能证明每个工业区都在经营仓库。
海滩仅对NLCD裸地且距真实海岸120米以内的部分作显式inferred辅助分类，不把所有沿海建成区称为海滩。

市界孔洞和缺角、海上行政多边形、Santa Monica/Beverly Hills等外部范围未用背景地形填满。图中的行政裁切边与显示底座不是网格漏块。
底座底面−50米及行政边缘立面是明确artistic_synthetic的项目显示底座，不是真实地质或城市边缘悬崖。

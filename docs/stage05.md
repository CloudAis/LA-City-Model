# 第五阶段：普通建筑、街区与城市体量

主检查点为 `scenes/stage05_city_medium.blend`，阶段四原工程保留。验收状态和实际数字以 `STATUS.md`、`outputs/stage05_city_medium_acceptance.json` 为准。

## 资料与可编辑结构

标准建筑库 `data/processed/stage05/buildings.sqlite` 的 `buildings` 表以 `i` 为稳定整型索引、`uid` 为来源唯一ID。`geom` 是项目米制局部坐标WKB，`attrs`保存来源、年代、原始字段、匹配、类型、高度方法、分部和推断。`active=0`的旧轮廓保留，停止生成主体。原始LARIAC文件、阶段二标准库和California PBF均不改写。

县数据原始轮廓是航测屋顶轮廓，不是已核实的地面外墙/地籍线。模型明确以它作为足迹代理。OSM属性仅在IoU≥0.45后关联；有县编号的OSM高度很可能沿用同一来源，不能算独立测量。新增OSM轮廓需要≥30m²且与活动主轮廓重叠≤5%，避免两个来源重复建模。明确拆除标记只在没有有力活动轮廓匹配时停止旧主体，年代仍未知，原记录不删除。

全市以1000m、Downtown以250m、两个近景以125m质心半开网格归属。建筑不按块边裁断，同一ID只归属一个块，越界部分保持完整。`mesh_index.json`记录原点、世界包围盒和SHA。Blender的`building_index`面属性关联SQLite.i；共享模块点属性也保存该索引。可在编辑模式按属性选择某栋建筑，或修改SQLite/生成脚本后构建相应块。合并网格不是百万个独立Blender对象。

`10_Buildings_AUTHORING_editable`保留作者网格；`10_Buildings_RUNTIME_simplified_static_alternative`保留独立简化网格。每栋仅显示其中一套。概览版本保留轮廓、高度关系和庭院，屋顶可简化为平面包络；作者版本的有依据/类型默认坡屋顶保留脊线。静态替换不等于已实现动态运行时LOD。

## 高度、地面与天际线

优先使用有定义的公布屋顶/整体高度，再使用OSM明确高度或分部、层数推算、明确标注的县字段解释、类型估计。没有随机高度。`HEIGHT ×1200/3937`仍只是美国测量英尺/相对高度的候选解释，尚未找到正式字段字典证明定义；OSM导入值近似相同不能反过来证明官方字段定义。`ELEV`与OSM`ele`不进入NAVD88地面或绝对屋顶高程。

U.S. Bank Tower物业公布1018国际英尺，转换310.2864m，属于舍入公布资料，不是测量控制。Wilshire Grand结构工程师公布1100英尺/335.28m是含尖塔的总高；主体保留单独的屋面候选值及OSM分部，尖塔为明确标注的窄幅几何近似，位置/轮廓仍待阶段八研究。没有把整个足迹挤出到335m。OSM的楼层、物业故事数及各分部仍可能定义不同，不声称已完全消除资料冲突。

地面来自阶段四当前显示地形和道路切口回填查询，缺样才回退原始DTM；地面仍为NAVD88米。每栋边界按≤20m采样并含内部代表点，统一楼面高于最高样点0.18m，基础低于最低样点0.30m；这是合理化台基推断，不是实测基础。高差>8m、入口超过8步或未解析地面项列入缺口，不能冒充已通过建筑落地验收。复杂山坡需分台地/实测资料后继续修整。多个离散部件目前共享所属建筑的楼面基准，必要时须分部复核。

OSM分部按垂直区间进行足迹并集，各区间间差集封顶/封底，形成退台、裙房和塔身。没有同时保留贯穿全高的父体与完整塔体。分部未覆盖完整高度时，最高部分配剩余高度是显式推断。

## 类型、模块与表现边界

13种类型由明确用途/材质/遗产标签支持，信息不足保持unclassified，不按街区名称猜建筑风格。类型影响缺测层高、屋顶默认、材质与窗格节奏。实际房屋不因属于Historic Core就自动改成砖石风格。色彩、窗格、门厅、雨棚和通用HVAC大多是标注推断，现有材质/颜色标签仅覆盖少数建筑并保留作研究；当前网格主要使用类型调色板，不能把标签存在当成已经逐栋映射。

Downtown作者层含立面UV窗格、已知分部退台、薄女儿墙、屋顶HVAC和入口模块。近景作者层增加最多180个/栋的几何凹窗、玻璃、侧壁和共享窗框；超预算墙面使用简化窗格。两个近景区是本阶段初版，不代表阶段六/七的逐栋外观考证已完成。入口门板和雨棚是外观代理，未建立可进入室内；没有依据的阳台、消防梯、水箱、太阳能板不批量安放。

`assets/buildings/stage05_modules.blend`提供窗框、入口门、车库门、空调、栏杆、女儿墙、雨棚、台阶、消防梯、太阳能板和水箱模板。重复实例由Geometry Nodes点属性控制尺寸与旋转，保持共享网格。未被观测支持的模板可以留在库中但不安放。全部为本项目程序化几何和材质，没有第三方建筑照片纹理。

完整作者数据驻留在.blend内，默认仅显示焦点范围。内嵌`STAGE05_VIEW_PRESETS.py`切换Historic Core、Civic Center、Downtown和全市概览；全市离线检查允许高于实时预算。默认可见预算包含GN实际实例三角形，不能只计点数。GPU/显存和实时FPS未知。GLB、材质烘焙、运行时流送和交互查看器留待阶段九。

## 执行与验证

```bash
cd /workspace/Base
./project env
./project run --stage 5 --region city --quality medium
./project check --stage 5 --region city --quality medium
```

`scripts/stage05*.py`分别执行原始PBF提取、关联/清洗、分部复核、建筑网格、摄像机、Blender保存/重开、来源登记、统计/地图和样本比对。未实现区域/质量与阶段六至十、export明确退出3。已注册输出哈希变化时停止，避免静默覆盖用户编辑；可变输入变化先保留旧检查点，再显式重建受影响块。

真实CPU渲染在`work/previews/stage05`。三个天际线机位和两条街景使用地理固定坐标；升高的机位另记距地高度。数据/模型比较使用同机位投影，不能只凭“像洛杉矶”判断。独立进程重开检查实际顶点、面、法线、材质与ID，样本从保存文件导出后再与原轮廓比较；浮点计算吻合不代表源数据测绘精度。

几何凹窗网格可能有T形边接点，拓扑报告逐栋记录；非零时不声称水密。全市没有逐栋现场核对。阶段四的净空、源层级冲突、远道路遮盖和备用地形LOD接口缺口继续保留。

## 本轮实际修正与查看约定

当前有效建筑1096502栋，Downtown7316栋，两个近景合计104栋；具体数字以验收JSON为准。区域集合B5_Authoring_*、B5_Runtime_*、B5_Modules_*对应城市、Downtown、Historic Core和Civic Center；其重组经过整个建筑/点实例几何与材质/ID/变换哈希复核。

Blender4.3新网格面默认呈平滑着色，本轮已显式关闭建筑及盒体模块的平滑，保留原地形的专用法线。float32后的屋顶微面翻向、7个building=no非建筑区域和3个极异常未核实高度候选均有实际修正记录。65栋报告高度/小结构用途冲突改为用途未知而不压低报告值。新参考影像只支持低层环境判断，实际采集日期和准确高度仍未知，没有进入模型纹理。

Wilshire尖塔基点改为最高OSM分部内部代表点，半径限制在其支撑域内；不是为同框移动建筑。整体高度335.28m与主体/屋面候选仍分别记录。NW/NE/S三张图的虚拟相机分别距采样地面80/60/20m，不声称是地面拍摄或公开观景台。

默认显隐经过实际三角形上限约束，最终缩到约150m；这不是全部工作窗没有建模。全市离线图约3273万可见三角形，整个.blend约1.126亿唯一使用网格三角形，编辑/离线内存高于未来实时查看器预算。CPU图仍有采样噪声，材料和近景界面并未达到最终写实验收。

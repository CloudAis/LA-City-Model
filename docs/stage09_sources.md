# 本地查看器的来源与使用条件

查看器底部常显©OpenStreetMap contributors，并链接https://www.openstreetmap.org/copyright。OSM源数据适用ODbL1.0；数据库权利与模型图片、软件代码的许可分别处理。没有抓取OSM标准地图瓦片或使用远程底图纹理。模型中的OSM来源属性、ID及推断说明保留在本地属性包。

USGS裸地DEM、Census TIGER/Line 2025、NLCD2021及洛杉矶市/县资料继承阶段02–08逐项登记的采集年、单位、精度和条款。LARIAC县轮廓不因进入本包就成为本项目原创数据；未核实高度定义及再分发限制保持原登记，不提供整包统一商业授权。阶段06地标和近景建筑是保留观察盲区的资料引导近似，不能称为测绘成果。

便携包`docs/source_history/`附带已有完整来源登记的副本；其中原始路径指向原项目的数据档案，原始大文件、研究照片和全城编辑工程没有随查看包重复打包。完整来源和参考卡仍保存在原项目。模型使用的PBR为阶段08本项目原创通用纹理，非研究照片直接贴图。原始照片的逐图授权不会被替换为软件MIT许可。

Three.js0.179.1与meshoptimizer1.3.0的MIT许可保存在便携包`licenses/`和原查看器`viewer/public/licenses/`。TypeScript、Vite等开发依赖由package-lock锁定，运行便携包无需安装Node依赖；开发依赖条款以对应包自带许可为准。

本阶段没有新增原始地理资料下载、公开上传或商业发布；只是对已登记来源的本地模型优化和离线查看交付。光照参考日期2025-09-21不代表混合年份资料属于该日城市快照。

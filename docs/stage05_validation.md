# 第五阶段验证边界

模型保存/退出、独立重开和实际渲染分进程执行，最终日志`work/logs/stage05/final_shading_blender.log`；早期预算、微面朝向和计算投影失败日志保留作诊断，不算最终通过。

`blender_check.json`检查实际保存网格所有使用顶点、三角形、材质索引、建筑ID、米制、屋顶面朝向与硬边标记。112639571为全部唯一使用网格三角形，1001323为保存默认显隐的实际可见数（含共享GN实例）。离线检查图单独记录可见数，超过实时预算时不称实时场景通过。

`building_sample_audit.json`从.blend中提取62栋实际几何，再与标准数据库比较，覆盖13类型、真正多部件、庭院、分部、架空、高层、山坡以及异常候选的估算替代。高度目标包括独立模块的顶部，避免女儿墙/设备被漏计。相符只验证实现没有改坏输入，源高度、外墙位置、材料及年份自身仍可能不准确。

2D投影并集会产生面积约1e-13至1e-26m²、有效宽度约1e-14m的GEOS数值伪环。检查仅在**投影测量**中排除同时小于1e-10m²、宽度小于1e-8m的伪环，保留原网格和记录；没有改动模型来填庭院。21/62仍有真实T形接点/非水密警告，不标水密通过。

`actual_spire_support.json`对保存模型的8个尖塔基点与实际最高支撑顶面进行接触检查；总高335.28m来自公布整体高度，不是全足迹屋面。位置/轮廓仍为近似。`same_camera_comparison.json`使用真实机位、来源包络与保存网格，公布尖塔单独画，不将不同距离的像素高度直接比较，也不冒充独立街景影像复核。

`placement_audit.json`是采样楼面/台基检查：6151个高台基警告、305个入口连接待核实；`urban_interface_audit.json`有208处代理轮廓/估算路面重叠。均不是已通过的工程接口，Civic地面过渡仍需改进。资料不足的楼面、层高、材质与外观推断在SQLite和实例记录中保留。

`region_collections.json`以5051个建筑/模块对象的顶点、拓扑、材质、ID、UV、变换和显隐计算哈希，确认仅组织集合没有改变几何，并重开核对。`model_container_integrity.json`记录环境短暂断连恢复后的原生压缩文件检验；环境离线原因未知，不归因于GPU或网络策略。

增量运行验证的是相同输入已登记输出的SHA复用，不宣称已经执行新云环境完整冷构建。未实现门禁和构建互斥通过实际子进程退出码验证。全部接受状态以outputs/stage05_city_medium_acceptance.json和STATUS.md为准。

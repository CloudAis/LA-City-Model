## 高度语义

LARIAC6 产品指南明确交付坐标为美国测量英尺；没有查到 HEIGHT/ELEV 官方字段字典。
原字段原样保留，height_candidate_m=HEIGHT×(1200/3937) 标为 inferred；height_m、roof_height_m、min_height_m、levels 仍未知。
因此“原 HEIGHT 缺失率约 0.002392%”与“已核实高度缺失率 100%”同时成立，分母和含义见统计。
不把 ELEV 当地面。地面单独从 USGS NAVD88 DEM 采样，4 个结构代表点无地面值保留 null。
候选 (ELEV−HEIGHT) 与 Downtown DEM 的残差诊断可帮助研究，不证明字段定义或垂直基准。
使用候选体量必须在后续阶段明确批准的建模策略中保留推断标识；当前检查点不挤出建筑高度。

## 变化与对应

- temporal_corrections.csv 有 70,109 条源数据 New/Modified 等历史更新记录，按 DATE_ 分配 2008–2014、2014–2017、2017–2020 等区间，精确事件日期未知。
- 这不是已核验的 2020–2026 新增/拆除清单。新建、重建、火灾影响、地标改名或立面变化仍需近期官方许可/影像/档案逐项补核。
- 9 对建筑依据显式 OLD_BLD_ID 建立对应，并计算实际 IoU 和质心距离；旧市级 2014 样本只作对照，不叠加建第二份模型。
- 3 对完全重合归档轮廓按明确要素采集年选择新记录；原记录保留于原始与标准观察档案。
- 市 GIS 与 Census 海岸/水域边界差异已量化。没有据此推断行政区扩张或物理海岸变迁。

## 可继续与缺口

已足以开始下一阶段的真实地形与土地覆盖处理，以及道路/建筑水平位置概览。
建筑高度关系和道路跨层连通性需要额外语义资料；不得用轮廓精度替代此缺口。
近景门窗、入口、退台、路缘、屋顶设施与地标外观研究尚不足，需要后续独立资料。
县/市源数据公开再分发授权尚未明确，不能将联邦 public domain 权利扩张到这些资料与外观照片。
所有数值精度未知项保持 unknown，坐标小数位、栅格分辨率和网页更新时间不证明测量准确度。

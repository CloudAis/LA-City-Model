# 第八阶段材质与纹理约定

本库为项目脚本原创的视觉材质，不是建筑实物取样、照片扫描或材料厂家测量值。它不改变既有足迹、道路位置、地形高程或来源精度。所有颜色、表面微结构和粗糙度属 `artistic_synthetic_original`；实际材质与建筑年代的推断边界继续保留。阶段08是否完成还须看实际Blender场景、四光照图与GLB回载报告；纹理生成通过不等于场景验收通过。

## 资源与重建

参数在 `config/stage08_materials.json`，脚本为 `scripts/stage08_textures.py`，实际资源与SHA在 `assets/materials/stage08/registry.json`。执行：

```sh
.venv/bin/python scripts/stage08_textures.py generate
.venv/bin/python scripts/stage08_textures.py check
```

固定种子20261021，每个材质再由名称派生稳定子种子；几何构建和纹理生成不共享可变随机状态。纹理目录按脚本/配置的内容指纹命名，输入变更会保留先前目录与登记；已登记文件被改动时停止，不静默覆盖用户编辑。相同输入再次执行会逐文件核对SHA并读取缓存。

库包含沥青、混凝土、石材/水泥铺装、砖、灰泥、涂料、玻璃、裸金属、屋面、裸土、草地、树叶、水面及道路标线14类。每类有1024、512、256像素三档，分别用于近景、街区与远景；它们是同一个原创标量场的降采样版本，不冒充提高原始资料精度。实际文件体积与110MiB预算由生成报告核对。

## 物理尺度与UV

`tile_size_m=[宽,高]` 是一遍UV重复对应的米制尺寸。将建筑/地面真实米制坐标除以相应尺寸写入UV，不能将每个不同大小的墙面都任意压成一张0–1纹理。竖直墙面U沿水平边长、V沿Z；水平路面U/V沿项目米制X/Y；曲面需沿面弧长展开、接缝置于不显眼部位。独立叶片使用单叶0–1UV，不按世界地表平铺。建筑立面接缝与实际保存网格的UV必须另行检查，此纹理脚本无法证明模型已展开正确。

典型单元：沥青8×8m、混凝土/灰泥/铺装4×4m、金属2×2m、屋面及土壤8×8m、水12×12m。砖贴图覆盖3.84×1.20m，即16列×16行的0.24×0.075m砖节距、9mm砂浆缝；错缝排砖跨完整图块无奇偶断裂。铺装为1×1m板节距、9mm推断缝。砖块尺寸、铺装接缝并非具体建筑工程测量值。

实际每轴纹素密度记录在登记的 `texel_density_px_per_m`。例如4m贴图近景256px/m、街区128px/m、远景64px/m；8m贴图分别128/64/32px/m。砖的两个物理轴范围不同，登记分别给出，不用单一像素值掩盖其差别。近景材质远离相机时可换低档资源；本阶段作者场景静态选择不构成已实现运行时流送。

颜色的低频变化控制在配置范围内；沥青没有满屏深裂缝或夸张补丁，砂粒/混凝土孔隙/灰泥为不同粗糙尺度。为限制重复感，可在真正独立构件间施加稳定的整数UV偏移及轻微材质色因子；不要对需要真实连续砖缝的同一墙体逐三角面随机旋转UV。没有依据的道路修补、污渍和材料替换不称为真实养护记录。

## PBR通道与色彩空间

每档为三张PNG：

| 文件 | 色彩空间 | 用途 |
| --- | --- | --- |
| `base_color` | sRGB | 基础颜色；只有叶片具有形状Alpha |
| `normal` | Non-Color | 切线空间OpenGL +Y法线，R=+T、G=+B、B=+N |
| `orm` | Non-Color | R=1，G=感知粗糙度，B=金属度 |

ORM的R通道常数1只表示不附加遮蔽，**不是已烘焙的城市几何AO**。粗糙度和金属度均为线性数据；不能对其做sRGB解码。法线来自有米制幅值的周期标量高度场的导数，编码前归一化，缩小分辨率后重新归一化；玻璃法线平坦。法线只扰动光照，不增加几何形变或提高地形精度。连接Image Texture（Non-Color）→Normal Map（Tangent Space，Strength1）→Principled Normal，不能把RGB直接接着色器法线，也不手动翻绿通道。导入器对glTF/Blender UV约定的转换须由实际导出回载核对。

生成器明确处理PNG行号向下而UV V轴向上：若图像高度场的行导数为dy，OpenGL法线绿分量取+dy；独立已知斜面的两个三维切向量叉积用来验证该方向，不仅检查法线RGB是否处于0–255。实际方向误差记录在 `normal_png_row_down_uv_v_up_geometric_direction_max_error`。

裸金属使用金属度1，涂料、玻璃、水、道路标线和普通矿物表面均为0。涂漆金属以涂层材质表现，不能仅因基底是钢而把漆面设成金属1。玻璃为IOR1.5的非金属，水IOR1.333；它们使用独立粗糙度、颜色及透射参数。

玻璃标准版透射0.72，水0.28，均避免以Alpha混合模拟整座建筑。glTF通过 `KHR_materials_transmission` 保留透射；不支持该扩展的实时环境应采用登记的有色不透明介电兼容版，并明确其没有真实透射/室内。玻璃不是镜面金属。不同建筑可用记录在场景内的粗糙度/颜色因子变体，不能宣称逐栋实测玻璃参数。树叶为双面Alpha Mask，阈值0.4；优先遮罩而非整树Alpha Blend，以减少排序问题。夜窗发光应在单独、固定种子的表面/材质中实现，不修改日间材料的基础物理类别。

## 寻址、接缝与实时资源

周期图像两对边的像素逐字节相同；生成后实际重开所有PNG，核对尺寸、数据范围、法线正Z与量化单位长度误差。检查值与每个文件SHA均在登记中。该检查证明贴图边缘连续，不证明城市UV、切线或模型法线无误。

Blender重复寻址为Repeat，插值Linear；glTF采样器目标为wrapS/wrapT=10497（REPEAT）、magFilter=9729（LINEAR）、minFilter=9987（LINEAR_MIPMAP_LINEAR）。PNG本身不携带完整mipmap链，实时查看器在加载时实际生成mipmap；不能仅因PNG存在就宣称已验证所有GPU的过滤行为。叶片单UV应避免跨叶边重复；Alpha边缘有透明区，不将纹理拉伸到多叶共用无间隔的UV图集。

材质已使用单张ORM合并三种标量数据；重复大面使用可平铺资源，比将不同米制重复单元硬拼进图集更合适。当前未把14类强行合为单个图集，避免破坏Repeat寻址和边缘。未来跨资产图集必须保留足够像素扩边、UV岛隔离和mipmap安全间隔，并以实际导出统计决定是否必要。

这些PNG是原始程序设计的最终可兼容采样结果，Blender保留可编辑参数和节点连接。旧阶段程序节点若无法进入glTF，不应直接宣称等价导出；本阶段用这些纹理驱动的Principled兼容材质，或在单独副本显式烘焙后核对。不能用只保存节点截图代替实际纹理。

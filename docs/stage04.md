# 第四阶段：真实交通空间结构

坐标、原点、单位、NAVD88地面基准与阶段三完全相同。只执行交通层，不构建阶段五城市建筑。

- 原始PBF：`data/raw/stage04/osm/california-20261021.osm.pbf`，1,333,217,331字节。
  文件头数据库状态2026-10-20T20:23:47Z；这是OSM数据库时刻，**不是采集日期或整城同日实况**。
  保留原始way/node ID、tag、version、编辑时间。采集年份与数字测绘精度未知。
- 2025 Census道路为独立覆盖比较来源，不与OSM重复生成同一道路；原数据不改写。
- 市政桥梁1907、信号设施5592、Metro站点107/线路6实际分页获取，全部ID与服务器count相符。
  500ID的长URL出现404，改为80ID短请求后逐批核验；不是忽略错误或绕过网络限制。
- USGS裸地DTM沿用阶段三。没有将DTM当桥面，没有采用来源不明的OSM ele或City净空字段作为高程。
- `California MUTCD 2026` 3A/3B实际取得并阅读；同向白线、对向黄线、白色横道/停止线为风格依据。
  标线/设施布置不是现状逐项测绘；普通线0.12m，州道边线0.15m为配置化视觉近似。

完整逐文件地址、请求参数、下载时间、SHA、坐标/单位/基准/精度/许可未知项见 `data/processed/stage04/source_registry.json`。
原始PBF覆盖California；工作数据只选市界+100m上下文，建模按既定洛杉矶市界裁切，不擅自加入Santa Monica/Beverly Hills。

## 道路拓扑与断面

264862条道路/通道way；427521个图节点、601712条分段边、1157334条有向弧。
只以相同原始OSM节点建立连接，二维交叉不会自动打通；保留单行、bridge/tunnel/layer、名称、access、turn:lanes等原tag。
图包含步行与车辆通道，不冒充完成交通法规/转向限制关系的导航引擎；OSM restriction关系未提取。
1024个连通分量可能包含真实私有通道、终点、市界裁切和缺测，不能把它们全部称为断路错误或全部称为正常。

断面按高速、匝道、主次干道、居住、服务、停车、步行/自行车分类；参数在 `config/stage04.yaml`。
OSM宽度优先，带ft/feet/英尺英寸的值实际转米；无效/复合值不强行解释。车道数缺失按类别估算。
单行缺失按OSM默认语义处理并标推断；reversible/alternating保留状态，不声称真实时段通行。
`estimated_parameters.csv`逐way列出车道/宽度来源和全部推断字段。高度、绝对高程、layer、净空分别记录。
没有为所有道路使用同一宽度。source geometry、参数与每个分块的mesh face属性可以继续编辑。

## 高程与真实性边界

`stage04_profiles.py`从DTM估计道路纵断面，共2126717个采样点；共享节点保持同高。
全局坡度约束传播到真实相连道路，避免局部桥面尖峰；不同道路类别采用不同上限。车辆纵断面超限数为0。
步道1717、自行车道25条超车辆式坡度预算的记录保留；台阶/山地通道不能通过抬平伪造可行驶坡道。

按OSM相对层级检查7011处跨层交叉：6961处满足估算净空；50处存在源网络、层级或净空冲突。
另191处没有共享节点又缺少足够层级依据，仍为unknown。**未把它们算作通过**。
估算桥面厚0.65m、净空目标5.2m，隧道深度约7m；不是现状净空、工程设计或测得绝对桥面标高。
layer仅决定相对约束，最终求解不直接把layer数值当真实米制高度。
桥跨与匝道的总体高度可达地面以上约35.83m，仍属推断，需要后续测得资料替换。

Downtown地面使用阶段三的独立变体，原DTM与原网格全部保留。
道路断面整平和侧坡处理记录于`roadbed_adjustments.json`，局部最大改动约17.55m。
这类大修整反映推断高程对底座的影响，**不能解释为当地真实填挖方**；附近实测桥面/匝道资料是重要缺口。
模型远区贴合所选地形LOD，Downtown以细网格和局部道路变体为主；渲染几何的坡度异常另行检测，不能只引用纵断面检查。

## 重点区与交通设施

Downtown同层路面先做几何并集；人行道做差集，路缘转角圆整。避免路口多层共面路面重叠。
根据真实节点/官方或OSM信号观测选择路口，横道、停止线、转向标线、杆架及无障碍过渡为明确标注的近似布置。
无障碍过渡实际从人行道/路缘中切开并生成过渡斜面；不把埋在人行道下的平面当作坡道。
标线为合并几何；桥墩、护栏、灯杆、枕木/站棚采用共享mesh实例。
桥墩按估算间距布置，避开已知下层道路交叉走廊；缺少真实桥墩定位和基础资料。
US101/CA110检查窗从实际ref-tagged交叉位置计算，位于Downtown工作窗附近的真实地理位置，未移动立交来构图。

另4713条非道路要素保留原始ID/标签/位置：轨道、站台、跑道/滑行道/机坪及设施参考。
运行轨道与废弃/拆除/拟建等标签分开；地下轨道几何受地形遮挡，不伪造为地面铁路。
站台采用实际OSM几何，Downtown少量站棚为简化推断。机场宽度用标签或45m/18m默认并记录。
港区采用真实道路/铁路和官方Port研究范围；不是港口泊位/装卸系统工程复原。
没有识别出明确的noise_barrier时不虚构隔音墙；来源中的普通wall/fence不自动当隔音设施。
建筑入口将在阶段05–07依据建筑和入口资料衔接，本阶段仅建立人行道相对路面约0.15m的接口约定。

## 分块、LOD与运行

1000m交通块与阶段三地形同格，局部XY与全局平移分离；每个源way保持统一宽度和纵断面规则。
`mesh_index.json`记录材质、块原点、SHA、角色、显隐；`roads.json`记录稳定ID、所属区域与tile_ids。
远处完整service/path/parking资产存入`full_far`隐藏集合；默认显示远区主要街道概览、Downtown细节及交通设施。
这是静态显示预设，运行时LOD切换/GLB/查看器仍留待阶段九。默认可见三角形是否符合预算由实际Blender检查报告给出。

```bash
cd /workspace/Base
./project env
./project run --stage 4 --region city --quality medium
./project check --stage 4 --region city --quality medium
```

同输入重跑验证缓存与模型/预览哈希，不重下PBF。输入改变时停止覆盖并要求保留现有成果，增量重建只处理受影响资产。
当前阶段四只实现并实际验收city/medium；其他区域/质量任务明确返回“未实现”，不冒充成功。
首次重建依次执行extract/data/other_extract/profiles/build/post/sources/audit/maps，再注册实际数据、保存并独立进程重开渲染。
阶段05–10和所有export仍返回3；等待用户下一部分。

## 实际网格修正与检查口径

第一轮发现合并地形路面会掩盖下穿高速。已将379条重点道路按受约束纵断面单独建面，切开28块派生地形中的道路空间，保留原始DTM和阶段三网格；挡土过渡面为推断。
桥面采用内部高程误差目标3.5cm的自适应细分，修复单凭边界三角化造成的跨层插值误差；这是计算采样误差目标，不是测绘精度。
单独映射的桥上人行道，依据同层、平行且15m内的车辆桥面推断连接及约15cm高差，见bridge_sidewalks.json。
实际车辆跨层414处抽查达到4.5m显示异常筛查阈值；不等同于法规净空或实测5.2m。
桥面顶面与地形相交、桥板底部与土体相交分别报告。桥板/桥台的接触不能在缺少真实跨径边界时全部称为桥面穿地，也不能全部算通过。

水域及原有河道细化块继续使用LOD0；其他远处地形使用LOD2，原始替代LOD保留。
局部路面、轨道、枕木和支撑与新地形重新衔接。水文参考仅在受影响处重贴，仍不是测得水位。
细分不会提高原始数据精度。所有局部填挖、道路高程、支撑位置及普通材质必须保留inferred标记。

## Blender内查看

主文件包含完整交通数据。为控制启动视图开销，默认静态显示Historic Core附近约1km范围，并隐藏部分高密度细节。
这不是已经实现动态流送；所有源网格仍存于工程。城市总览检查图临时启用完整概览层，离线渲染面数可以高于运行时预算。
在Blender的Text Editor打开内嵌`STAGE04_VIEW_PRESETS.py`，将preset设为city_overview、historic_core、civic_center或interchange再运行，可切换显隐范围。
原始备用地形LOD保留；派生道路切口只修改当前检查使用的LOD，阶段九切换其他LOD前必须同时更新道路接口，不能假称全部组合已经通过阶段四检查。
资源库：`assets/street_furniture/stage04_prototypes.blend`，包含可复用的信号杆架、护栏、桥墩、枕木、简化站棚模板等共享mesh；不是制造商精确产品模型。

主要检查报告：audit.json、actual_mesh_crossings.json、rail_road_crossings.json、tile_seams.json、tangent_sliver_review.json、clearance_repair.json、deck_sampling.json、deck_terrain_cuts.json、paint_drape.json。
道路剖面坡度与实际三角形坡度分别记录。远处概览网格和微小三角形的坡度警告保留，不能用剖面通过替代全部实际网格通过。

## 最终显示检查修正

隐藏对象重新打开后，matrix_world与bound_box可能尚未得到有效视口求值。预览与内嵌视图脚本现在使用网格实际顶点及保存的平移/旋转/缩放计算范围；正交相机按图像宽高比包含完整市域和4km工作区。构建时批量写显隐；切换检查图时只对变化项调用RNA setter，保证显示图刷新。

典型路口首次出现的浅色碎片经检查是重复地形穿过路面，不是数米悬空的标线。1504个标线重心与实际路面高差0.0079964–0.0080036m；原地形在其中36处高于标线，最大约4.9mm。已按实际路面三角形XY并集从16块派生地形中裁去被路面覆盖的部分，路面填补这些开口；该抽样重复地形命中由1504降至0。道路XY/Z、原始DEM及阶段三网格不变，地面查询接口由实际路面减0.06m提供。数值报告见intersection_paint_support.json、intersection_ground_occlusion.json及pavement_ground_occlusion.json。

远区概览道路仍可能局部被粗地形遮盖；没有将整城可视连续性或全部横坡称为通过。精细路缘、实测分隔带/绿带/隔音设施、桥台跨径和完整铁路净空仍需补充资料与逐区修正。
